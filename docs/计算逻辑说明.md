## 二、预测未来出货量

### 2.1 算法说明

**算法名称**: 移动平均法（Moving Average）

**文件位置**: `backend/app/services/predictor.py`

**计算公式**:
```
预测值 = AVERAGE(最近N天出货量)
```

### 2.2 计算过程

#### Step 1: 计算最近4天的移动平均值

```
最近4天出货量: 184, 181, 181, 178
移动平均值 = (184 + 181 + 181 + 178) / 4 = 181 kg
```

#### Step 2: 预测未来5天的出货量

| 天数 | 预测出货量(kg) | 计算说明 |
|------|----------------|----------|
| 第1天 | 181 | AVERAGE(184,181,181,178) |
| 第2天 | 181 | 同上 |
| 第3天 | 181 | 同上 |
| 第4天 | 181 | 同上 |
| 第5天 | 181 | 同上 |
| **合计** | **905** | 181 × 5 |

**预测总出货量 = 905 kg**

## 三、计算安全库存

### 3.1 算法说明

**文件位置**: `backend/app/services/predictor.py`

**【修改后的公式】**:
```
安全库存 = 标准差 × 安全库存系数 × √LeadTime
```

**关键点**: 使用 `√LeadTime` 而非 `LeadTime`，用于考虑预测误差的方差。

### 3.2 计算历史预测误差

**误差计算方法**:
```
误差 = 实际值 - 预测值
```

**【修改】只保留最近30天的误差值**，避免使用所有历史数据。

#### 最近30天的误差列表

```
[-2.5, -50.0, +24.5, +24.5, +29.5, +6.0, +56.0, +37.0, +53.0, +66.0,
 -15.0, -28.0, +35.0, +9.0, -25.0, +46.0, +21.0, +24.0, +10.0, +7.0,
 -37.0, +16.0, -43.0, -56.0, -22.0, -28.0, -14.0, -45.0, -69.0, -20.0]
```

### 3.3 计算误差标准差

```
STDEV(最近30天误差) ≈ 38.97 kg
```

### 3.4 计算安全库存

```
安全库存 = 38.97 × 1.65 × √5
        = 38.97 × 1.65 × 2.236
        = 143.80 kg
```

**安全库存 = 143.80 kg**（约144 kg）

## 四、库存模拟

### 4.1 算法说明

**文件位置**: `backend/app/services/inventory_calculator.py`

**计算公式**:
```
当日库存 = 昨日库存 - 当日出货 + 当日到货
```

### 4.2 到货判断规则

**【核心判断逻辑】**:
```
如果 昨日库存 - 今日出货 <= 安全库存:
    需要到货 = True
    下单日期 = 到货日期 - LeadTime
    到货数量 = MOQ
```

## 五、下单建议

### 5.1 判断过程详解

**第10天的判断**:
```
第9天结束库存: 371 kg
第10天预测出货: 181 kg
出货后库存 = 371 - 181 = 190 kg

判断: 190 <= 144（安全库存）? 是 → 需要到货
```

**下单日期计算**:
```
到货日期 = 第10天
下单日期 = 第10天 - 5天 = 第5天
```

### 5.2 下单建议汇总

| 项目 | 值 | 说明 |
|------|-----|------|
| 是否需要下单 | **是** | 第10天库存低于安全库存 |
| 首次下单日期 | **第5天** | 到货日期10 - LeadTime5 |
| 首次下单数量 | **1000 kg** | MOQ |
| 总下单次数 | 2次 | 第5天、第11天 |
| 总下单量 | 2000 kg | 1000 × 2 |
| 最低库存 | 104 kg | 第16天出货后 |
